# The Big Pivot -- Contractor Marketplace

Detroit's quality-gated contractor marketplace connecting vetted tradespeople with government, commercial, and residential clients.

## Demo
Open BigPivot_Demo.html in any browser -- no install required.

## Pages
- Landing page with hero, stats, trade categories, No Jack Legs section
- Contractor listing with filters and search
- Contractor profile (Marcus Thompson -- Master Electrician)
- Post a Job (3-step form with success state)
- Contractor Dashboard with earnings and bid opportunities

## Documents
- BigPivot_StrategicAnalysis -- Full business strategy, gap analysis, grants, partnership structure
- BigPivot_TechnicalRequirements -- Complete technical spec for developers

## Tech Stack (Full App)
Next.js 14, Tailwind CSS, Supabase, Stripe Connect, Resend
